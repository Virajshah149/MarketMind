# MarketMind

AI-powered corporate dependency and supply-chain intelligence platform.

## Goal

MarketMind maps dependencies between Indian listed companies and simulates how shocks can propagate through the network.

## Core Features

- Company dependency mapping
- Supplier/customer relationship extraction
- Evidence-backed relationships
- Supply-chain shock simulation
- Historical event analysis
- Backtesting
- Interactive dependency graph

## Initial Scope

- 50 Indian listed companies
- Annual-report based dependency extraction
- Graph-based propagation
- Historical validation
